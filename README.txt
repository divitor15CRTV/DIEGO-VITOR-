SITE EU VOU · WOMAN — PRONTO PARA PUBLICAR NA VERCEL
====================================================

ESTE SITE JÁ VEM COM A SUA MOLDURA ORIGINAL (PNG COM FUNDO TRANSPARENTE).

COMO FUNCIONA:
1. A pessoa acessa o endereço do site.
2. Escolhe uma foto JPG, PNG ou WebP.
3. A moldura Eu Vou · Woman aparece sobre a foto automaticamente.
4. Pode arrastar a foto e controlar o zoom se desejar.
5. Clica em "Baixar minha foto com a moldura" para salvar a imagem PNG de 1080x1080.

PRIVACIDADE:
A imagem enviada é processada no navegador do visitante. Nenhuma foto é armazenada no site, e não é necessário banco de dados.

COMO PUBLICAR NA VERCEL (SEM PRECISAR PROGRAMAR):
Método 1 — GitHub:
1. Crie um repositório no GitHub e envie os arquivos desta pasta para a raiz do repositório.
2. No painel Vercel, selecione Add New > Project e importe o repositório.
3. Se solicitado, escolha Framework Preset: Other; mantenha o diretório raiz como ./ e deixe Build Command vazio.
4. Clique Deploy e compartilhe o link .vercel.app gerado.

Método 2 — CLI da Vercel:
1. Instale Node.js e execute `npm i -g vercel`.
2. Abra um terminal na pasta que contém este README e execute `vercel`.
3. Para produção execute `vercel --prod`.

MUDAR A MOLDURA:
Substitua o arquivo assets/moldura-woman.png por outro PNG transparente, preferencialmente em formato quadrado 1080 x 1080, mantendo o nome do arquivo. Depois, publique a atualização.

DICA:
Não envie o arquivo ZIP diretamente como se fosse o código do repositório. Extraia os arquivos e envie para a raiz do repositório. O arquivo inicial deve se chamar index.html.

ARQUIVOS:
- index.html          Site completo (design + funcionalidade)
- assets/moldura-woman.png  Moldura original enviada
- vercel.json         Configuração para Vercel
- README.txt          Este guia
